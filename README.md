# Games

Αυτό είναι το κεντρικό repository `seemsfunny21/games` για την ενιαία συλλογή παιχνιδιών.

## Οργάνωση

- `index.html`: κοινό μενού, ίδιο οπτικό μοτίβο με το Applications.
- `shared/theme.css`: ενιαίο σκούρο μπλε θέμα, glow, κάρτες και προσαρμογή κινητού/υπολογιστή.
- `sw.js`: offline cache με περιορισμό μόνο στο `/games/`.
- Κάθε παιχνίδι έχει ξεχωριστό υποφάκελο και δικό του `index.html`.

## Σημαντικό

**Οι 14 φάκελοι είναι αρχικοί χώροι (placeholders), όχι ολοκληρωμένα παιχνίδια.** Θα προστεθούν κανονικοί μηχανισμοί, έλεγχοι και αποθήκευση προόδου ανά παιχνίδι.

## Μελλοντική μεταφορά

Μετά την ολοκλήρωση των νέων παιχνιδιών, θα μεταφέρουμε με ασφάλεια τα αρχικά παιχνίδια εδώ. Για να μη χαθούν παρτίδες, θα εξετάσουμε τη μεταφορά αποθηκεύσεων ανά παιχνίδι πριν αλλάξουν τα παλιά URLs. Το Applications θα παραμείνει ο κεντρικός εκκινητής.
