# Games — 14 offline παιχνίδια

Συλλογή από δεκατέσσερα ανεξάρτητα παιχνίδια HTML/CSS/JavaScript, σχεδιασμένα με το ίδιο **Premium Blue** θέμα του Applications.

## Περιεχόμενα
- Ναυμαχία (εναντίον υπολογιστή)
- Pyramid Solitaire (κάρτες και άθροισμα 13)
- Blackjack (χωρίς πραγματικά χρήματα)
- Mahjong Solitaire (ελεύθερες πλευρές)
- Flow Connect (χρωματιστές διαδρομές)
- Παζλ 15
- Falling Blocks
- Brick Breaker
- Space Invaders
- Maze Chase
- Frogger
- Κρυπτόλεξο (ελληνικό)
- Κρεμάλα (ελληνικά)
- Memory Match

Κάθε παιχνίδι έχει δικό του υποφάκελο και `game.js`, αλλά μοιράζεται τα `shared/theme.css` και `shared/core.js`. Η λειτουργία είναι τοπική και δεν χρησιμοποιείται Supabase.

Η βασική κατάσταση/πρόοδος αποθηκεύεται τοπικά στα παιχνίδια γύρων, ενώ τα arcade χρησιμοποιούν προσωπικά ρεκόρ και επανεκκίνηση. Η offline cache προφορτώνει τα απαραίτητα αρχεία μετά την πρώτη online επίσκεψη. Στα παιχνίδια πραγματικού χρόνου, το τρέχον καρέ/γύρος δεν διατηρείται σε επανεκκίνηση.

## Offline και δημοσίευση
Ανοίξτε την αρχική σελίδα μετά τη δημοσίευση μέσω GitHub Pages. Το service worker `sw.js` αποθηκεύει όλα τα HTML/JS/CSS αρχεία στο scope `/games/`. Το repository δεν επηρεάζει το cache ή τις αποθηκεύσεις άλλων PWA.

## Έλεγχοι
Το GitHub workflow `Games browser smoke tests` ελέγχει σύνταξη JavaScript και τη βασική λειτουργία όλων των παιχνιδιών σε Chromium σε κινητό και υπολογιστή.

## Μελλοντική ενοποίηση
Τα υπάρχοντα παιχνίδια θα μεταφερθούν **ξεχωριστά**, με διατήρηση των παλιών URL/αποθηκεύσεων μέχρι να δοκιμαστεί η μεταφορά. Το Applications θα παραμείνει launcher.
